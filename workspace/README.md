# 值班席位租约协调器（Duty-Seat Lease Coordinator）

把 **撤离方案发布、车队调度、封存审查** 等业务写操作接到「席位 + 单调世代号 + 租约宽限边界」上，
保证交班、网络抖动、多控制台同时在线时**绝不出现双主**；紧急失联时由两名合格见证人接管；
业务请求带指纹实现**精确一次语义**；崩溃后自动恢复世代、租约边界与请求判定。

零第三方依赖（Node.js ≥ 20，仅用内置 `http` / `node:test` / `crypto`），
持久化使用带 `fsync` 的只增事件日志。

---

## 快速开始

```bash
# 直接运行（无需安装依赖）
node src/server.js
# → http://localhost:8080  （管理页面 + 模拟控制台）

# Docker
docker compose up --build
```

演示数据在首次启动时自动播种：1 个夜班、3 个席位（撤离/车队/封存），租约 TTL 20s，
配持有人、候选接班人、3 名见证资格各异的人员。重置可用页面上的「重置演示数据」或
`node scripts/seed.js --reset`。

离线脚本一遍走完所有场景（正常交班 / 断连恢复 / 竞争接管 / 指纹幂等 / 见证失败路径）：

```bash
node scripts/demo.js
```

## 它保证什么

| 场景 | 保证 |
| --- | --- |
| 协作交班 | 接班人确认 **且** 持有人交出两步齐备，才原子切换到 `generation+1`；两步可任意顺序、可在崩溃后继续 |
| 交班完成后 | 旧控制台的写操作与心跳一律被围栏拒绝（`STALE_GENERATION` / `NOT_HOLDER`），无双主窗口 |
| 多控制台在线 | 每个请求携带 `(seatId, holderId, generation)`，服务端 CAS 校验，只有当前世代能写 |
| 短暂断连 | 租约未到宽限边界，任何人不能取得该席位；恢复后心跳可续租 |
| 失联过期 | 过期后旧持有人**只能读状态，不能续租、不能写**；新持有人由交班或紧急接管产生 |
| 紧急接管 | 原持有人失联达到门槛 **且** 两名**具备资格、互不相同**的见证人签名，才夺取为连续 `generation+1` |
| 接管失败路径 | 过早接管、申请人自证、无资格、资格被撤销、重复见证、旧世代申请、夺取后补签 —— 全部拒绝，不改变归属 |
| 并发竞争 | 多个竞争者各自收证，夺取提交走世代 CAS：只有一个胜出，世代只 +1 且连续 |
| 请求重试 | `fingerprint` 相同且内容完全相同 → 返回**原判定**（成功或业务失败都记住） |
| 指纹滥用 | 复用同一指纹但席位/世代/操作/载荷不同 → `FINGERPRINT_REUSED` 拒绝并审计 |
| 已接受请求 | 之后的交班/接管永不回滚它；旧世代的**相同**重试仍可拿回原结果 |
| 时钟偏差 | 以服务端时钟为唯一权威；客户端时钟完全不参与授权。演示用的时钟快进也持久化，重启不能续命 |
| 进程崩溃 | 提交=追加事件+fsync；交出/确认/夺取中途死掉，重启重放日志得到唯一可判定状态，尾部半行自动截断 |

## 控制台导览（管理页面）

- **席位与租约倒计时**：持有人、世代、TTL 进度条；持有人可点「心跳续租」「发起交班」，过期后非持有人可「申请紧急接管」。
- **待确认交接**：两步确认的勾选状态，接班人/持有人各有自己的按钮。
- **紧急接管见证**：开放中的申请、已有/还缺的见证人、席位是否仍在租约内。
- **模拟控制台身份**：多开浏览器标签页选择不同身份 = 多个控制台同时在线；持有人卡片上可直接发业务请求，
  可切换「携带世代」、编辑载荷、固定/更换指纹（含「微改载荷但保留指纹」的冲突实验按钮）、开自动心跳。
- **被围栏拒绝的操作 / 已接受请求**：审计流（拒绝原因 + 指纹 + 时间）。
- **演示工具条**：逻辑时钟快进 25s（模拟失联）、时钟归零、`SIGKILL` 崩溃（容器自动拉起验证恢复）、重置数据。

建议动手剧本：

1. **正常交班**：以「周援」身份发起交接给「苏岚」→ 换标签页以「苏岚」确认 → 「周援」交出。
   再用周援卡片上 gen=1 发业务 → 被拒；相同指纹重放原请求 → 拿到原判定。
2. **断连恢复**：勾选某席位「自动心跳(7s)」，等待观察倒计时持续顺延；关掉标签页（停心跳），
   快进 25s → 席位过期，旧身份心跳被拒；他人可发起接管。
3. **竞争接管**：席位过期后「应急值班员」「竞争值班员」各开一个申请，分别让见证人甲乙签名，
   观察只有一个连续新世代、另一个 `SUPERSEDED`。
4. **崩溃**：在交接只完成一步、或接管刚成功后点「模拟进程崩溃」，等容器/进程重启，状态完全一致。


## API 摘要

详见 [API.md](./API.md)。所有写操作是 `POST /api/...` JSON；
身份由 `X-Actor-Id` 头或 `actorId` 字段携带（演示用途，生产应替换为真实认证）。

核心端点：`/api/shifts`、`/api/heartbeat`、`/api/handover/{start,confirm,release,cancel}`、
`/api/takeover/{open,attest}`、`/api/adapter/evaluate`（业务围栏）、
`/api/state`（快照）、`/api/events`（SSE 实时推送）。

## 生产化备注

- `ENABLE_DEV_TOOLS=0` 关闭时钟快进 / 崩溃 / 重置端点；演示偏移不使用。
- 事件日志建议挂载到可靠磁盘并定期快照+日志压缩（当前实现保持简单，重放全量日志）。
- 横向扩容时把 `EventStore` 换为单写者的 WAL/Raft 日志即可，内核状态机不变。
